# Alpha Labs — brand and project scope

**Public name:** Alpha Labs.
**Repository slug (proposed):** `alpha-labs`.
**Purpose:** multi-market quantitative research, evidence validation, risk, monitoring and, only after separate approval, execution.
**Initial market research:** BTC, ETH and SOL. Equities/ETFs are a subsequent adapter track.
**Existing browser implementation:** the `apps/sites` offline research site, not a live trading system.
**Technical identifiers:** Python package `alpha_lab` is retained to avoid unnecessary import churn. Browser localStorage key `solana_alpha_lab_v01` intentionally remains for backwards compatibility and to preserve existing research data.
**Brand clearance:** domain and trademark availability have not been checked.
**Release boundaries:** no historical profitability claim; no exchange credentials; no wallet signing; no live trading.

# v0.4 signed-task protocol — security foundation only

This is a standalone fail-closed verifier and SQLite nonce reservation implementation, **not a remotely executable privileged agent**.

Envelope JSON has exactly two fields: `task` and `signature`. The task has exactly `schema` (integer 4), `device`, `nonce` (32 lowercase hex characters from a cryptographically secure RNG), `issued_at`, `expires_at`, `operation`, and `repo`. The signature is HMAC-SHA256 over the domain-separated canonical JSON payload. Maximum lifetime is 300 seconds. Device identity is bound into the signature. Duplicate nonces are rejected by a durable SQLite unique constraint.

**Security boundary:** This implementation permits only `repo_status` and `repo_log` on `alpha-labs` and `Q3HASH`. It does not execute commands or connect to GitHub. The signing key must be generated and stored outside GitHub and never included in issue bodies, repository files or logs. A shared-key signer must be separated from the worker's execution authority; compromise of the signing key authorises tasks within the allowlist.

**Not yet implemented:** independent signer provisioning, secure key rotation, integration into the GitHub polling worker, persistent recovery of delivery receipts, privileged filesystem/Git operations, Android boot restart, Android background survival, and full shell access. None of these may be claimed as complete.

Run: `cd tools/termux_github_bridge && python -m unittest -v test_signed_protocol_v4.py`.

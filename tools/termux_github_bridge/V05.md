# v0.5 Ed25519 verifier — standalone foundation

This change introduces Ed25519 public-key verification with device binding, strict v0.4 task policy, domain-separated canonical messages, trusted key IDs, short task lifetimes and SQLite replay reservation. **It does not install, activate, or replace any Termux worker.** No private keys are generated or stored in GitHub.

Requires Python package `cryptography`. Test locally with `python -m unittest -v test_ed25519_protocol_v5.py`.

**Next gates:** independent signer implementation and enrolment, secure device public-key provisioning, key revocation and rotation, durable receipt reconciliation, and integration tests before replacing the v0.3 operational worker. The existing HMAC v0.4 worker is not modified. Full-system command access remains prohibited.
